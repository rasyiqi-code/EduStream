# **App Name**: EduStream

## Core Features:

- Video Upload: Add educational videos using direct MP4 URLs or YouTube embed codes.
- Content Browsing: Browse educational content using an intuitive, YouTube-like interface.
- Video Search: Find educational content using a simple search feature.
- Course Playlists: Organize videos into course-specific playlists.
- Full-Screen Player: Provide a full-screen video player for distraction-free learning.

## Style Guidelines:

- Primary color: Muted blue (#64B5F6), evoking professionalism and calm.
- Background color: Very light blue (#E3F2FD), providing a clean, uncluttered backdrop.
- Accent color: Light grayish-blue (#90CAF9), used for interactive elements, differing from the primary in saturation and brightness to create visual contrast.
- Body and headline font: 'Inter' (sans-serif) for a modern and clean look suitable for both headings and body text.
- Simple, clear icons that support ease of navigation.
- A clean, YouTube-like layout that is easy to navigate.
- Subtle transitions for a smooth user experience.
